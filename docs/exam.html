③ 기존 내용의 뒤에, 현재 디렉터리의 상세 내용이 추가된다.

15. uniq 명령의 특징을 기술하시오.
정답 uniq 명령은 연속적인 행으로 중복된 내용만 중복으로 처리하여, 다른 행에 있는 내용은 중복 처리하지 않는다.
16. sort 명령의 특징
정답

옵션 없이 사용하면 숫자 → 영어 대문자 → 영어 소문자 → 한글 순서로 정렬된다.

정답 split -l 5 u.txt ch6

11. 일반 프로세스와 데몬 프로세스의 차이를 설명하시오.
정답
일반 프로세스: 사용자가 커널에 의해 실행되었다가 실행이 끝나면 종료하는 프로세스

정답 ps -ef | grep cron
19. 로그아웃한 다음에도 find / -name sort.txt 명령이 계속 실행하도록 하는 명령을 기술하시오.

20. PID가 5000인 프로세스를 kill 5000으로 종료하려는데 종료되지 않는다. 강제로 종료하려면?
