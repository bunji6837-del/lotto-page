4. PPT 문제 정리

운영체제 / 스케줄링

설명정답외우는 말
FCFS를 선점 형태로 변형, Time Sharing System, Time Slice 사용라운드 로빈시간 조각으로 번갈아 CPU 할당
실행시간이 가장 짧은 프로세스에게 먼저 CPU 할당, 비선점, 선점형은 SRTSJF짧은 작업 먼저
HRN 우선순위 계산식(W + S) / SW는 기다린 시간, S는 서비스 시간
전원을 켜면 OS 전에 자기진단과 주변기기 점검BIOS컴퓨터 켜자마자 먼저 실행
CPU와 입출력 장치 속도 차이 보완 위해 잠시 저장버퍼링속도 차이 줄이기
준비 상태 프로세스에 CPU 할당하여 실행 상태로 전환디스패치준비 → 실행

운영체제 처리 방식

설명정답
한 개 CPU에서 여러 프로그램을 기억장치에 보관 후 번갈아 처리다중 프로그래밍 시스템
자료를 일정 기간 또는 일정량 모아서 한꺼번에 처리일괄 처리 시스템
CPU 시간을 작은 시간량으로 나누어 번갈아 처리시분할 시스템
여러 개 CPU와 한 개 주기억 장치로 여러 프로그램 동시 처리다중 처리 시스템

5. 정보시스템기반기술 주관식 3문제

주관식은 점수 비중이 높으니까 아래 서술형 답안 형태로 외우면 된다.

1번. 프로그램과 프로세스에 대해 설명하시오

구분설명
프로그램보조기억장치에 저장되어 있는 명령어들의 집합이다. 아직 실행되지 않은 정적인 상태이다.
프로세스프로그램이 메모리에 적재되어 CPU에 의해 실행 중인 상태이다. 실행 중인 프로그램이라고 할 수 있다.

서술형 답안

프로그램은 보조기억장치에 저장되어 있는 명령어들의 집합으로 아직 실행되지 않은 정적인 상태이다.
프로세스는 프로그램이 메모리에 적재되어 CPU에 의해 실행 중인 상태로, 실행 중인 프로그램을 의미한다.

짧게 외우기: 프로그램 = 실행 전 파일, 프로세스 = 실행 중인 프로그램

2번. 문맥교환에 대해 설명하시오

문맥교환은 CPU가 현재 실행 중인 프로세스의 상태 정보를 저장하고, 다음에 실행할 프로세스의 상태 정보를 불러와 CPU를 넘겨주는 작업이다.

여러 프로세스를 번갈아 실행하기 위해 필요하지만, 너무 자주 발생하면 오버헤드가 증가하여 성능이 떨어질 수 있다.

서술형 답안

문맥교환은 CPU가 현재 실행 중인 프로세스의 상태 정보를 저장하고,
다음에 실행할 프로세스의 상태 정보를 불러와 CPU를 할당하는 작업이다.
여러 프로세스를 번갈아 실행하기 위해 필요하지만, 자주 발생하면 오버헤드가 증가한다.

짧게 외우기: 현재 프로세스 상태 저장 + 다음 프로세스 상태 복원

3번. 스레드와 프로세스에 대해 설명하시오

구분설명
프로세스실행 중인 프로그램이며, 독립적인 메모리 공간과 자원을 가진다.
스레드프로세스 안에서 실행되는 작업의 작은 단위이다. 같은 프로세스 안의 스레드들은 코드, 데이터, 자원을 공유할 수 있다.

서술형 답안

프로세스는 실행 중인 프로그램으로 독립적인 메모리 공간과 자원을 가진다.
스레드는 프로세스 안에서 실행되는 작업의 작은 단위이며,
같은 프로세스 안의 스레드들은 코드와 데이터 등 자원을 공유할 수 있다.

짧게 외우기: 프로세스 = 실행 중인 프로그램, 스레드 = 프로세스 안의 실행 단위
