5장 셸

01. 셸의 세 가지 기능에 해당하지 않는 것은?
② 문서 편집 기능
03. 사용자 계정의 기본 셸이 저장된 파일은?
④ /etc/passwd
04. chsh -s dash user1 명령 오류 원인은?
④ 바꾸려는 셸을 절대 경로로 지정해야 한다.
05. 현재 디렉터리에 파일이 있을 때 ls t?.exe 결과에서 제외되는 파일은?
① t.exe
07. ls -l >> data 명령을 수행하면?
③ 기존 내용 뒤에 현재 디렉터리의 상세 내용이 추가된다.
09. 히스토리를 이용하여 명령을 재실행하는 방법이 아닌 것은?
④ !!번호
10. 우분투 리눅스에서 배시셸의 사용자 환경 설정 파일이 아닌 것은?
① .login
12. 로그인 셸과 서브 셸의 차이
로그인 셸: 사용자가 로그인하면 자동으로 실행되는 기본 셸
서브 셸: 사용자가 프롬프트에서 실행한 다른 셸
13. userX의 로그인 셸을 대시셸로 바꾸는 명령
chsh -s /bin/dash userX
16. 표준 출력과 표준 오류를 모두 s.out에 저장하는 명령
명령 > s.out 2>&1
20. 수정된 환경 파일을 적용하는 방법
1. source ./.bashrc
2. . ./.bashrc
3. 로그아웃 후 다시 로그인

6장 접근 권한

01. 리눅스 접근 권한에서 사용자 카테고리에 해당하지 않는 것은?
② 세션
02. 리눅스 접근 권한 표기 문자가 아닌 것은?
④ a
03. 디렉터리에 r 권한이 없는 경우 옳은 설명은?
③ 해당 디렉터리의 내용을 ls 명령으로 확인할 수 없다.
04. -rw-r----- 에서 그룹 권한은?
② 읽기
07. text.txt 파일을 소유자만 읽기 가능, 그룹/기타 권한 없음으로 설정
③ chmod 400 test.txt
10. 파일이나 디렉터리에 설정된 특수 접근 권한을 확인할 수 있는 명령
④ ls
11. 파일 읽기 권한과 디렉터리 읽기 권한 차이
파일 읽기: 파일을 읽거나 복사할 수 있다.
디렉터리 읽기: ls 명령으로 디렉터리 목록을 볼 수 있다.
12. 디렉터리에 실행 권한이 없다는 의미
cd 명령으로 해당 디렉터리로 이동할 수 없다.
15. 접근 권한을 숫자로 표기
rwxr-xr-x = 755
rw-r--r-- = 644
19. 스티키 비트
디렉터리에 스티키 비트가 설정되어 있으면 누구나 파일을 생성할 수 있지만, 다른 사용자가 생성한 파일은 삭제할 수 없다.
20. /bin 디렉터리에서 SetUID가 설정된 명령 예시
gpasswd, mount, newgrp, passwd, su, umount

7장 파일 검색 / 정렬

01. find 명령으로 파일 종류를 지정하여 검색할 때 사용하는 옵션
③ -type
03. 파일 위치를 찾을 때 사용할 수 없는 명령
② file
04. /etc/services 파일에서 ISO를 행번호와 함께 출력
③ grep -n ISO /etc/services
06. sort 명령에서 대소문자를 구분하지 않기 위한 옵션
① -f
08. 파일을 비교할 때 사용하는 명령이 아닌 것
② comp
14. ex.txt 파일을 두 번째 필드의 역순으로 정렬
sort -k2 -r ex.txt
15. uniq 명령의 특징
uniq 명령은 연속적인 행으로 중복된 내용만 중복으로 처리한다. 떨어져 있는 중복 행은 중복으로 처리하지 않는다.
16. sort 명령 특징
텍스트 파일의 내용을 정렬하여 화면으로 출력한다.
옵션 없이 사용하면 숫자 → 영어 대문자 → 영어 소문자 → 한글 순서로 정렬된다.
19. u.txt 파일을 5행씩 분할하고 PREFIX를 ch07로 지정
split -l 5 u.txt ch6

8장 프로세스

01. 현재 실행되고 있는 프로그램
③ 프로세스
03. 시스템에서 특정 서비스를 제공하는 프로세스
② 데몬 프로세스
08. 포그라운드 작업을 잠시 중단할 때 사용하는 키
② Ctrl + Z
09. 작업 번호가 3번인 작업을 종료하려고 할 때 kill 다음에 지정할 것
③ %3
11. 일반 프로세스와 데몬 프로세스의 차이
일반 프로세스: 사용자가 실행하고, 실행이 끝나면 종료되는 프로세스
데몬 프로세스: 특정 서비스를 제공하기 위해 대기하다가 요청이 오면 실행되는 프로세스
13. cron 프로세스를 사용자 ID와 터미널 번호가 보이도록 검색
ps -ef | grep cron
19. 로그아웃 후에도 find 명령이 계속 실행되도록 하는 명령
nohup find / -name sort.txt &
20. PID 5000 프로세스가 kill 5000으로 종료되지 않을 때 강제 종료
kill -9 5000
